# Ascendroid 見た目と音の決まり(0.54.0)

見た目と音を作り直したとき(ブランチ `visual-overhaul`)の決まりと、決めたことの理由。あとで手を入れるときは、まずここを読む。
ゲームの仕組み(規則・数値・敵とカードの中身・文章)はこの作業では変えていない。

## 1. 方向: 案A「白熱」

**時間は距離、脅威は熱。**

- 巨大な塔の暗がり。自機 K-7(左)と敵(右)のあいだの空間がタイムラインで、敵の予定は熱の塊として右から滑ってくる。近づくほど白く熱くなる。
- 枠や窓は置かない。暗がり(煤の黒)の中の光で読ませる。自機と敵は逆光の影。
- 色は意味を伝えるためだけに使う(3章)。飾りの色は足さない。
- 音は硬く、電子的に(8章)。

方向性の見本(案A・案B)は `tools/mock/direction/` にある。ユーザーが案A を選び、次を指示した:

1. A を土台に、タイムラインの情報を増やし、見やすく分かりやすく。面積を前の実装より小さくしない。
2. 地図の斜めに登る形は良いが、見本は細かくて目が疲れそう。
3. 敵を押してズーム&詳細、上下スワイプの状態確認は、同じ働きのものを入れる。
4. 見本の音は柔らかすぎる・可愛すぎる。サイバーパンクらしく。

| --- | --- | --- |
| `--soot` | `#070605` | 地。煤の黒(少し暖かい黒。青い黒にしない) |
| `--iron` / `--iron2` | `#15120f` / `#221d19` | 持ち上がった面(カード・ボタン・選択肢) |
| `--seam` | `#332b24` | 継ぎ目の線 |
| `--bone` | `#f1e8da` | 主の文字、決定ボタン |

| `--frost` / `--frost-d` | `#cdefe6` / `#2f9c90` | **自分と操作**: 今の線、選んだカード、予想の帯、ブロック、コスト、狙い、通ってきた道 |
| `--ember` → `--flame` → `--glow` | `#b8321a` → `#ff7a1f` → `#ffe6ae` | **脅威 = 熱**: 敵の攻撃(遠い赤 → 近い白)、被弾、警戒が上がる、エリート・ボス |
| `--arc` / `--arc2` | `#b7a0ff` / `#e2d8ff` | **不安定と JUST**(溶接の光): 不安定な行動の輪、体勢の帯、JUST、アトミック、属性の名前 |

- 熱の色は `index.html` の `heatCol(h)`(h = 0 遠い 〜 1 近い)で作る。印の色は「何サイクル後か」で決まり、9サイクル先より遠いものはいちばん暗い赤。
- 敵の灯りは熱の色、自機の灯り(目・刃・襟巻き)は冷たい色。
- レア度はカードの上の縁の色: 初期・コモン = 鋼色 / アンコモン = 青紫(焼き戻しの色)/ レア = 金。

## 4. 字体

- 数字と欧文: **Big Shoulders Display**(同梱、可変ウェイト。`--f-num`)。ダメージ・コスト・耐久などの数字と、JUST・ASCENDROID などの欧文に使う。太さは 800〜900 が基本。
- 日本語: 端末のゴシック体(`--f-body`: Hiragino Kaku Gothic / Noto Sans JP / Yu Gothic)。見出しは 900、本文は 400〜700。
  - 同梱しない理由: 日本語の字体は1つの太さで 1.5MB 以上あり、工房で足した文の字に追従できない(足りない字だけ別の字体になる)。
- 文字は最小限。数字は大きく(線路の印 17px、カードの値 25px)、説明の文は 9.5〜12.5px。字間を空けるのは見出しだけ。

## 5. 配置

### 舞台の大きさ
- 基準は **844×390**(`#stage`)。`layout()`(index.html)が画面に合わせて拡大し、余った分は**横 1040・縦 540 まで舞台を広げる**(16:9 なら 844×475)。
  それより縦長(タブレットなど)は上下に `#wrap` の背景が出る。
- 位置はすべて `LAY`(layout() が作る)から決める。**画面の座標を数字で直に書かない。** CSS へは `--x0` `--x1` `--px` `--yE` `--y0` `--dy` `--yS` `--floor` `--W` `--H` で渡している。
- 縦に余ると、線路の間隔(`LAY.dy`)が広がり、敵の絵が大きくなる。自機は部位の見出しに掛からない幅(高さ 200)まで。

### 戦闘: 5本の線路
```
 [見方] 　　　　1  2  3 … 18(サイクル)　　　　　　　　敵の名前 [≡]
        　　敵の行 ──■──────□────  だれが動くか / 窓(体勢・防壁・反撃・隙)/ 攻撃でない行動
 K-7   演算 ──────(3)(3)(3)──────
 (影)  武装 ────────────────────          敵(逆光の影)
       出力 ─────────────(10)────          ユニットは体の上の輪
       耐久 ──────────────────(24)
       機動 ────────────────────
        　自機の行 ◆▓▓▓──────────  使っているカードの帯 / 時限 / 射界
 耐久 ▬▬▬ 38　　　[ 手札 ]　　　　　　　　　　　96 ▬▬▬ [待機][リフレッシュ]
 [山札][キャッシュ][捨て札]
```
- **線路は自機の部位**(上から 演算・武装・出力・耐久・機動)。敵の攻撃は狙う部位の線路の上を来る。「いつ・どこに・どれだけ」が位置で読める。
  見本の案B の「五線 = 五つの部位」を、案A の見た目で取り入れた(ユーザーの指示1への答え)。
- 敵の行(いちばん上): 攻撃ならだれ(どのユニット)が撃つかの札と、そこから線路の印へ下りる線。攻撃でない行動(ブロックを得る・増幅など)は鋼色の札。
  行動の前後の窓(体勢 = 紫の斜線 / 防壁 = 鋼色の縦線 / 反撃 = 橙の破線 / 隙 = 冷たい色の帯)は、この行のすぐ下。
- 自機の行(いちばん下): 今使っているカードの帯、時限(丸)、射界(橙の斜線の帯。狙われる部位とダメージ)、こちらへのディレイ。
- 印(熱の塊): 丸の中の数字がダメージ。2サイクル以内は塗りつぶし。多段は小さい丸を線でつなぐ。不安定は紫の点線の輪が回る。▲▼ は増幅・虚弱で変わった攻撃。
- 次の攻撃が来る線路は、今からその印まで熱い線になり、部位の見出しも橙になる。近いほど背景の熱(`--threat`)と火の粉が増える。
- ブロックは「今」の線の手前の冷たい壁と、自機の行の左の数字。カードの防壁は、線路の上に残りサイクルぶんの冷たい帯。
- **予想**(カードを選んだとき): 冷たい帯が今から発動の時刻まで伸びる。帯の中の攻撃は白く脈打つ(発動の前に当たる)。
  **発動の前に止められる(ブレイクされる)なら、帯は橙になってそこで切れ、×が付く**(`PV.cutAt`。エンジンの見込みの結果を足しただけで、規則は変えていない)。
  不安定な行動に重なれば、その印が紫白に光る(JUST)。帯の先の丸い札に与えるダメージ・得るブロックが出て、押すと使う(カードをもう一度押しても同じ)。
  減る耐久は、自機の部位の目盛り・耐久の帯・敵の輪と足元の帯に点滅で出る。
- 敵: 本体の絵は床に立つ。**ユニットは体の上の輪**(弧が残りの耐久、中に数字。急所は二重の輪。左上にブロック、下に状態)。
  ユニットごとに絵を持つ敵(小隊・群れ)は、データの `at` の左右の順を保って、区画に収まる隊形(`FORM`)に並べる。足元の帯は急所の合計。
  敵全体の状態(増幅・加速・抵抗)とパッシブは右上、名前の下。

### 戦闘の中の見方の切り替え
| 見方 | 指 | マウス | キー |
| --- | --- | --- | --- |
| 手札を広げる(全文が読める) | 上へスワイプ | ホイール上 / 左上のボタン | ↑ |
| 自機の中(部位とパーツ・山札・キャッシュ・捨て札・独り言) | 下へスワイプ | ホイール下 / 左上のボタン(見ている間も押せる。もう一度押すと戻る) | ↓ |
| 敵の詳細(敵に寄って、行動の並び・パッシブ・段階変化・ユニット) | 敵を長押し(何も選んでいなければ押すだけ) | 右クリック | F |
| カードの拡大(全文と用語) | カードを長押し | 右クリック | — |
| 行動の中身 | 線路の印・帯を押す | クリック | — |

そのほかのキー: 数字 = カード・選択肢 / Enter = 使う・決定 / Esc = 戻る・取り消し・メニュー / R = リフレッシュ(入れ替え)/ W = 待機 / ←→ = カードを移る / Tab = 狙うユニットを移る / D = デッキ / M = メニュー。
キーは「同じ所を押したことにする」形で作ってある(`keydown` の処理が要素の `click()` を呼ぶ)。

### 地図
- 塔を斜めに登る。区画が進むごとに `MAPRISE`(15)上がり、3本の道は `MAPLANE`(60)離れる。横に送ると視点も一緒に登る(`mapFollow`)。
- 印は直径 40、区画の間隔 88(見本は 28 と 60 で細かすぎた。ユーザーの指示2)。
- 通ってきた道は冷たい線。今いる所は冷たい丸。選べる区画は白い輪(エリートは橙、保守通路は冷たい色)。
- 地図の底の熱(背景の橙)は、警戒のゲージ(−10〜+10)で濃くなる。

### 部屋・重ねる画面
- 枠は描かない。暗い面の上に、見出し(字間を空けた太字)・選択肢(鋼板)・決定(骨色のボタン)。
- カードの一覧は手札のカードを 1.3 倍にしたもの(`.cards .card`。ショップは 1.12 倍)。拡大は 1.75 倍(`.czoom`)。
- **一覧と拡大のカードは、文の長さに合わせて縦に伸びる**(手札は 96×136 で固定し、溢れたら文の下を薄くする)。文は工房で伸び縮みするので、高さを決め打ちにしない。
  拡大の倍率は CSS の `zoom` で掛ける(`transform` だと伸びた分が場所を取らない)。`zoom` の無いブラウザでは `@supports` の外の `transform` に戻る。

## 6. 部品

- **カード**(手札は 96×136。一覧と拡大は文に合わせて縦に伸びる): 上の縁 = レア度 / コスト(冷たい色の大きな数字)と、コストの数だけの目盛り / 属性(紫)と名前 / 記号と値 / 文。背景に種類の記号を薄く。
- **ボタン**: 決定 = 骨色の板に黒い字(`.btn`)。そうでないもの = 輪郭だけ(`.btn.ghost`)。丸いもの = 戦闘の右下(リフレッシュ・待機)。
- **選択肢**(`.opt`): 鋼板。選ぶと冷たい輪郭。
- **耐久**: 自機は骨色の帯、敵は橙の帯と輪。予告で減る分は点滅。
- **状態**: 記号 + 数字(枠なし)。色は意味の色(隙 = 冷たい色の塗り、クラック・侵食 = 冷たい色、ブロック = 鋼色、増幅 = 橙)。
- **記号**: `index.html` の `IC`(12×12 か 16×16 の線画、`currentColor`)。部位の記号は線路の左・カード・敵の詳細で同じものを使う。
- **絵**: 自機・敵は 0.53.0 までの線画の形をそのまま使い、色だけ「逆光の影」に当て直している(`retint`、`TINT_FOE`・`TINT_K7`)。
  形を変えなかった理由: 敵のユニットの在りか(`data/enemies.js` の `pt`)が絵の座標で書かれていて、データは変えられないため。自機には襟巻き(冷たい色)を足した。

## 7. 動き

0.49〜0.52 の決まり(溜め → 決め → 余韻、原因と結果をつなぐ、当たりは止まる・押される・光る・数字が同時、画面全体は光らせない)はそのまま。位置だけ新しい配置に合わせた。

- 時間が進むと、印が左へ滑る(1サイクル 110ms、`transform` で動かす)。
- カードを使うと、カードは自機の行へ吸い込まれ、自機が線路を横切って敵へ踏み込む(近接)/ 撃つ(遠隔)。
- 敵の攻撃は、印が「今」の線で弾け、狙う部位の見出しが橙に締まる。ブロックで受けたら壁が光る。
- JUST: 一瞬止まり、世界が暗く沈み、白紫の光と大きな「JUST」。ブレイクは冷たい色。
- 撃破: 敵が横に断たれて崩れる。
- 演出の最中に次のカードを押すと、演出を打ち切って受け付ける(当たりの数字と音は必ず出る)。
- **動きを減らす設定**(`prefers-reduced-motion`): 待ちを 40ms までに詰め、Web Animations の動き・火の粉・回る輪・点滅を止める。画面の切り替えの面も出さない。
- 重さの目安: 動かすのは `transform` と `opacity`。ぼかし(`filter: blur`)は使わない。光は放射のグラデーションと `box-shadow`。火の粉は 1秒30コマまで・40粒まで。

## 8. 音

`js/audio.js`。すべて Web Audio でその場で作る(素材のファイルは無い)。試聴は `tools/audio/index.html`。

- 方向: **硬く、電子的に。** 歪ませた矩形波と鋸波、FM の金属音、粗い雑音(標本を保持して段にしたもの)、短い遅延(167ms、返り 36%)。
  丸い鐘や柔らかい正弦波の旋律は使わない(見本の音が「柔らかすぎる・可愛すぎる」と言われたため)。正弦波は底の抜ける低音にだけ使う。
- 効果音(`SND.play(名前)`): 押す・選ぶ・1サイクル進む・近接(軽い/重い)・遠隔(軽い/重い)・ブロック・受けた・被弾・ディレイ・敵の行動・敵の溜め・JUST・ブレイク・自分がブレイク・ユニット破壊・撃破・リフレッシュ・引く・取り込む・買う・消す・回復・地図を進む・画面の切り替え・警戒の上下・戦闘に入る・勝つ・機能停止・ひとこと。
  - 1サイクル進むたびに低い刻みが鳴る(コストが耳で数えられる)。
  - 重さ(`weightOf`: コストの対数)で、近接・遠隔の長さと低音が変わる。
  - JUST と撃破のときは、曲の音量を一瞬下げる。
- 曲(`SND.music(場面)`): 16分の段を先読みして鳴らす。D のフリジア。
  - `battle` 112 / `elite` 118 / `boss` 126(拍/分): 四つ打ちと歪んだ低音。敵の攻撃が近いほど(`SND.heat`)低音が開き、刻みが強くなる。
  - `map` 84 / `room` 76 / `title` 70: 遅く、低いうなりとまばらな金属の音。
- 設定: 音量・効果音の入り切り・曲の入り切り(メニューと、タイトルの「音」)。端末ごとに `localStorage` の `asc.audio` に残る(セーブとは別)。
- 端末の音量と消音に従う。最初の操作で鳴り始める。画面が隠れている間は止める。

## 9. 決めたことと理由(迷った所)

- **見た目を別のファイルに分けた**(`css/app.css`): 前の CSS は版を重ねた上書きが 1400 行あり、直すより書き直すほうが確かだった。処理は `index.html` に残して、進行を変えないことを確かめやすくした。
- **進行の処理に足したもの**: 予想に `cutAt`(止められる時刻)を足しただけ。`computePreview` の中で、エンジンの見込みの結果(`interruptedAt`)を読んでいる。状態と乱数には触れていない。
- **透かす機能をやめた**(タイムラインを押すとキャラが透ける): 自機と敵が線路の外に立つので要らなくなった。`setPeek` は呼び出しだけ残して何もしない。
- **敵のユニットの並べ方**: データの `at`(本体の絵の中心からの位置)は前の広い区画に合わせた値なので、そのままでは収まらない。体に付くユニットは絵の中の在りか(`pt`)に輪を置き、絵を持つユニットは隊形に並べ直した。データは変えていない。
- **遊び方の文**(`showRules`): 画面の場所と操作を言っている文だけ、今の画面に合わせて書き直した(「奥の画面に…」「下の印は狙う部位」「タイムラインを押すとキャラが透ける」など)。規則を言っている文はそのまま。
- **足した画面の文字**: 「音」「音量」「効果音」「曲」(音の設定)、キーの説明(遊び方の中)、試聴ページの文。`aria-label` に「手札を広げる」「自機の状態」「発動」。カードや敵の文(`text/*.csv`)は変えていない。
- **版**: 0.54.0(`index.html` の `APP_VERSION` と `sw.js` の `VERSION`)。README の版の表は編集しない決まりなので、足していない。
- **日本語の字体を同梱しない**: 4章のとおり。
- **試遊版の公開**: 既にある試遊版・カード工房のアーティファクトには公開していない。新しいアーティファクトに出した。
- **手札から離れていく札は押せなくした**(`leaveHand`): 捨て札へ飛んでいく札が、古い `data-i` のまま 260ms 手札に残っていて押せた。押すと別の札を指すか、無い札を指して処理が止まる。main からある不具合で、マウスだけで遊ぶ play19 で見つかった。飛ばし始めた時点で `data-i` を外して押せなくするだけで、状態と乱数には触れていない。
- **火の粉は見た目専用の乱数で動かす**: `Math.random` を引かない(進行の乱数の並びに、見た目の処理が混ざらないように)。キャンバスは粒が通る範囲(敵の足元から左上へ約 150px)だけの大きさにした。全面のキャンバスだと、CPU 1/4 で 33ms を超えるコマが main の倍あった。
