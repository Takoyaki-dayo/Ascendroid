# Ascendroid 見た目と音の決まり(作業中)

見た目と音の作り直し(ブランチ `visual-overhaul`)の決まりと、決めたことの理由。作業の途中なので、下の「作業の記録」に進み具合も書く。最後に整えて、色・字体・部品・配置・動き・音・素材の一覧にする。

## 方向: 案A「白熱」

- 時間は距離、脅威は熱。自機 K-7(左)と敵(右)のあいだの空間がタイムライン。敵の予定は熱の塊で、近づくほど白く熱くなる。
- 枠や窓は置かず、暗がり(煤の黒)の中の光で読ませる。自機と敵は逆光の影。
- 色は意味だけ: 冷たい白緑 = 自分と操作 / 熱(赤→橙→白)= 脅威 / 溶接の光(紫白)= 不安定と JUST / 鋼色 = 敵の守り。

### ユーザーの指示(方向性の見本を見たあと)

1. 雰囲気は案A。案B はサイバーパンクではなくレトロ。
2. A を土台に、タイムラインの情報を増やし、見やすく分かりやすく。画面の中でタイムラインが占める面積を、前の実装より小さくしない。
3. 地図の形(斜めに登る)は好きだが、見本は細かくて目が疲れそう → 大きくする。
4. 敵を押してズーム&詳細、上下スワイプの状態確認は、同じ働きのものを必ず入れる。
5. 見本の音は柔らかすぎる・可愛すぎる。サイバーパンクらしく。

## 決めたことと理由

### 戦闘の配置: 5本の線路
- タイムラインを、K-7 の5つの部位(演算・武装・出力・耐久・機動)ごとの5本の線路にした。敵の攻撃は「狙う部位の線路」の上を滑ってくる。
  「いつ・どこに・どれだけ」が位置で読める(案B の五線の考えを、案A の暗がりと熱で描いた)。指示2への答え。
- 上に敵の行(だれが動くか、体勢・防壁・反撃・隙の窓、攻撃でない行動)、下に自機の行(使っているカードの帯、時限、射界)。
- 自機は左端、敵は右端に立ち、線路はそのあいだ。前の実装(上にタイムライン、下にキャラ)より、タイムラインの高さが増える。
- 画面は 844×390 を基準に、余った分は横 1040・縦 540 まで広げる(16:9 では縦が 475 になり、線路の間隔と自機・敵が大きくなる)。それより縦長の画面は上下に背景を足す。

### ファイルの分け方
- `css/app.css`: 見た目すべて。`index.html` には画面の骨組みと処理だけを残す。
- `js/audio.js`: 音。`assets/fonts/`: 同梱する字体。
- 進行の処理(状態を書き換える・乱数を引く関数)は `index.html` に残し、中身を変えない。`tools/publish/flowcheck.js` で main と比べる。

### 字体
- 数字と欧文: Big Shoulders Display(同梱。SIL OFL)。製鉄所の標識のような縦長の字で、熱と鋼の見た目に合う。
- 日本語: 端末のゴシック体(Hiragino / Noto Sans JP / Yu Gothic)。理由: 日本語の字体を同梱すると数MBになり、工房で足した文の字に追従できない。
