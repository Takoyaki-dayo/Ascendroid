# 塔の戦闘試作

サイバーパンク風ローグライク・カードゲームの戦闘試作(PWA)。
GitHub Pagesで公開し、AndroidのChromeから「ホーム画面に追加/インストール」すると全画面・横向きで起動する。

- `index.html` ゲーム本体(1ファイル)
- `manifest.webmanifest` アプリ設定(全画面・横向き)
- `sw.js` オフライン用。更新時は `VERSION` を上げる
- `icons/` アイコン(仮)
