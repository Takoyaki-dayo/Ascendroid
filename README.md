# Ascendroid

サイバーパンク風ローグライク・カードゲーム(開発中)。GitHub Pagesで公開し、AndroidのChromeから「アプリをインストール」すると全画面・横向きで起動する。

## ファイル

- `index.html` ゲーム本体の画面と演出
- `js/engine.js` ルールの処理(戦闘、手札の到着、地図の生成)。画面を持たないので、シミュレータからも使える
- `data/` ゲームのデータ。中身の一覧は企画書とは別のデータ一覧の資料にもまとめている
  - `parts.js` 部位とパーツ(付け替え候補も)、本体耐久
  - `cards.js` カード、最初のデッキ、珍しいカード、キーワードの説明
  - `enemies.js` 敵(行動パターン、反応・連携、学習で出るカード)と遭遇
  - `map.js` 地図(道の性格と部屋の中身)、報酬、ショップ、イベント
  - `lines.js` 独り言のセリフ
- `tools/datadoc.js` データ一覧の資料に載せる表を data から作る
- `tools/sim.js` 自動対戦のシミュレータ。`node tools/sim.js greedy 40` で遭遇ごと、`node tools/sim.js greedy 40 run` でラン全体
- `manifest.webmanifest` アプリ設定(全画面・横向き)
- `sw.js` オフライン用。データファイルを増やしたら CORE に足す
- `icons/` アイコン(仮)

## バージョン

`0.マイナー.パッチ` で管理する。機能の追加や画面の作り直しでマイナーを上げ、調整や修正ではパッチを上げる。遊べる形が固まったら 1.0.0。

- 更新するときは `index.html` の `APP_VERSION` と `sw.js` の `VERSION` を同じ値にする(sw.js を変えないと、インストール済みのアプリが古い版のままになる)
