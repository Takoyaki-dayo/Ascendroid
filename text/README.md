# ゲーム内の文章

ゲームに出る文章はこのフォルダの CSV が元です。表計算ソフトでそのまま開いて編集できます(UTF-8・BOM付き)。

直したら `node tools/text.js` を実行すると `data/text.js` が作り直され、ゲームに反映されます。`data/text.js` は自動生成なので直接は編集しません。

- 「キー」の列はプログラムが使う名前なので変えない
- 「(参考)」で始まる列は読み込まない(編集の手がかり用)
- 行を足すとき・消すときは、同じキーの書き方にそろえる

## ファイル

| ファイル | 中身 |
| --- | --- |
| `cards.csv` | カードの名前と効果の文 |
| `keywords.csv` | キーワードの名前と説明(カードの長押しや、説明の中のキーワードを押すと出る)。名前を変えると、カードの文で色が付く語や、押せる語も変わる |
| `parts.csv` | パーツの名前と効果の文 |
| `enemies.csv` | 敵の名前と行動の名前。キーは `敵.pat.番号`(行動の並びの何番目か、0から)、`敵.phase.番号`(耐久が減った後の並び)、`敵.react`(反応。パッシブの名前にもなる)、`敵.unit.ユニット`(ユニットの名前)、`敵.passive.番号`(パッシブの名前。番号は data の passives の何番目か。`敵.passive.phase` は耐久が減ると行動が変わるパッシブの名前)、`敵.broke.ユニット:番号`(そのユニットが破壊された後の並び)、`敵.say.*`(敵のひとこと。`start` 戦闘の始め、`pat:番号` その行動のとき、`anger` ディレイを受けて怒ったとき。同じひとことは1戦闘に1回) |
| `events.csv` | イベントのタイトル・本文・選択肢 |
| `lines.csv` | 独り言のセリフ。上の行の条件ほど優先。同じ条件の行が複数あれば、その中からランダムに1つ。`room:部屋の種類` は、どの条件にも当てはまらないときの一言 |
| `attrs.csv` | カードの属性(0.28.0)。名前はカードの名前の頭に付く(「〇〇された」+カード名)。テキストが空なら、属性の数値から効果の文を作る(「ヒットごとに、クラック1を与える。」)。属性の仕組みと数値は data/attrs.js |
| `terms.csv` | エリア・部屋・道・部位の名前、独り言の話し手、画面の短い文(`ui.mv.*` 敵の行動、`ui.pas.*` パッシブ、`ui.unit.*` ユニット、`ui.st.*` 敵の状態) |

## 差し込み

文の中の `{...}` はゲームが数値などに置き換えます。

- カード: `{dmg}` ダメージ、`{x}` 回数、`{block}` ブロック、`{delay}` ディレイ、`{crack}` クラック、`{draw}` 引く枚数、`{t}` 何サイクル後に効くか、`{tdmg}` 時限のダメージ、`{gain}` 得る充電、`{per}` 充電1あたりの量、`{sn}` `{sv}` 決まった量の充電の消費とその合計、`{dn}` `{dp}` 持続の回数・威力。ダメージとブロックはパーツの補正込みの値になる
- 敵のひとことは差し込みなし。短く、その敵の性格が出るように(1行に収まる長さ)
- セリフ: `{part}` 部位名、`{enemy}` 敵の名前、`{move}` 技の名前、`{t}` 残りサイクル、`{poise}` 構えを崩すのに要る一撃
- 画面の文: `{n}` 回復量

パーツやイベントの説明に出る数値は差し込みではなく、文に直接書いています。数値を変えたときは文も合わせて直します。

## 書き方の決まり

カードゲームの効果文の書き方にそろえます。

- ダメージ: 「8ダメージを与える。」/ 全体: 「敵のすべてのユニットに5ダメージを与える。」/ 複数回: 「2ダメージを2回与える。」
- ブロック: 「5ブロックを得る。」
- 状態: 「クラック2を与える。」「ディレイ3を与える。」「充電4を得る。」
- 引く: 「カードを2枚引く。」
- 条件つき: 「JUST：〜」のように、キーワードとコロン(全角)で始める
- 遅れて効く: 「4サイクル後、9ダメージを与える。」のように文で書く(0.22.0 から「時限」はキーワードにしない)
- 敵の行動の前の窓は「名前 窓/値」の形: 「体勢3/12」「防壁3/8」「反撃5/4」
- 言葉の決まり(0.22.0): カードが効くことは「発動」(使い終える、とは書かない)。敵の行動が止まることは「ブレイク」。JUSTで止められる敵の行動は「不安定」。自分の側の仕組みはカタカナ寄り(ブロック・ディレイ・クラック・アトミック・JUST)、敵の状態や窓は漢字(装甲・隙・体勢・防壁・反撃・増幅・加速・抵抗)
- 常に働く性質: 「アトミック。」のように文の頭に置く
- 近接か遠隔かはカードの絵のアイコンで分かるので、文には書かない
- カードの名前は《》、敵のユニットの名前は【】で囲む。画面ではそこを押すと説明が重なって出る(キーワードも、その文で最初に出たところが押せる)
- 「ユニット」は敵の1つの単位(1体の敵でも、部位に分かれていても使う)。自機の「部位」とは呼び分ける
- 文は「。」で終える。体言止めや「……」は使わない
